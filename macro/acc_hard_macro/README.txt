Hardened FP16 accelerator with 512 B SRAM

ICC2 export: final_1795071989 (routed DMA reset ECO).
Core location in the Tiny Tapeout wrapper: (5.52, 5.44) um, orientation N.
Core dimensions: 1367.12 x 214.88 um.
GDS contains the complete standard-cell and SRAM geometry.
LEF exposes the existing power stripes and signal pins.
The powered Verilog netlist is used for timing and gate-level simulation.
Full LVS compares the actual core and SRAM device connectivity.
DMA counter bit 7 has one explicit reset gate to avoid gate-level reset X-pessimism.
No local Magic diagnostic changes or antenna waivers are included.
